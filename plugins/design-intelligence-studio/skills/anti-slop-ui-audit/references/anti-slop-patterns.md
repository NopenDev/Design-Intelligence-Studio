# Common anti-pattern diagnostics

| Pattern | Diagnostic question | Better direction |
|---|---|---|
| Repeated rounded cards | Does each container encode grouping, selection, or elevation? | Use spacing and hierarchy where sufficient. |
| Gradient/glow decoration | Does it belong to brand, data, state, or spatial layering? | Build hierarchy through type, content, and composition first. |
| Generic hero | Does the opening show the product's characteristic value or interaction? | Lead with the subject-specific content or workflow. |
| Arbitrary bento | Does the grid encode a real relationship or priority? | Use sequence, comparison, timeline, or task structure. |
| Universal pills | Does shape still distinguish semantic roles? | Match geometry to component role. |
| Micro-label overload | Does each label aid orientation or hierarchy? | Remove redundant eyebrows and fake metadata. |
| AI marketing copy | Does the phrase describe a concrete action or outcome? | Use precise nouns and verbs. |
| Motion everywhere | What does each animation communicate? | Keep only meaningful feedback and transitions. |
| Design-system amnesia | Is a second token/component system being introduced? | Reuse verified project primitives. |
| Dashboard by default | Does a metric or chart support a real decision? | Structure around user workflow. |
| Decorative emptiness | Is the surface intentionally sparse? | Fix content/structure rather than filling space. |
| Scattered actions | Are same-scope actions grouped predictably? | Consolidate by object/workflow and reflow accessibly. |

A pattern is not automatically wrong. Evaluate intent, context, execution, accessibility, and consistency.
