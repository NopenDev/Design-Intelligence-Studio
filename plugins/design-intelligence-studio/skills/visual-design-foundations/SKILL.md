# Visual Design Foundations

## Hierarchy
Start with the user's scan goal. Rank content by importance, then assign the minimum signals needed: scale, weight, color role, position, and spacing. Avoid giving every element equal weight or over-signalling every level.

## Typography
Choose type by product character, language coverage, legibility, available weights, and loading cost. Establish named roles and a consistent scale. Keep body text comfortable, line lengths readable, and long content resilient. Use tabular figures for aligned numeric data when useful.

## Color
Build semantic roles rather than unrelated hex values. Check actual foreground/background pairs in all themes and states. Use accent color with restraint. State color must be accompanied by text, icon, or another cue.

## Composition and spacing
Use alignment, proximity, grouping, rhythm, and whitespace before adding containers. Equal relationships should use equal spacing tokens. Use grids to express real relationships, not arbitrary mosaics.

## Icons and imagery
Use a consistent icon family and stroke/fill logic. Do not use emoji as substitute UI icons. Distinguish decorative from informative imagery. Optimize image dimensions and preserve layout space.

## Charts and data
Choose chart form based on comparison, trend, distribution, composition, or relationship. Label axes and units, show source/context where needed, support accessible interpretation, and do not rely on color alone. Avoid charts that do not answer a decision question.
