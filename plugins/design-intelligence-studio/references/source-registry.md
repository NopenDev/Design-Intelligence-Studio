## Curation policy

- Select sources for practical value, clear ownership boundaries, and non-overlapping responsibilities.
- Preserve attribution and licensing notes for future maintenance; re-check upstream status before copying or redistributing source files.
- Upstream CLI, Python scripts, browser automation, MCP dependencies, and searchable data corpora are intentionally excluded.
- Do not imply a skill has been validated against a source project's full test suite unless that suite was actually run.
- Public projects and licenses can change; re-check the upstream repository at each release.
