# Design Intelligence Studio — 1.0.1 Skill Catalog

## Scope

Design Intelligence Studio 1.0.1 contains 14 skills: ten product/UI design skills and four software/data engineering skills. Each skill is separately discoverable; the routing guide determines when to combine them.

## Responsibilities

1. **UI/UX Intelligence** — product analysis, design intelligence, and orchestration.
2. **Frontend Art Direction** — visual concept and distinctive art direction.
3. **Product UX and Flows** — user journeys, task flows, and information architecture.
4. **Design System Engineering** — tokens, themes, components, and governance.
5. **Visual Design Foundations** — typography, color, spacing, composition, and hierarchy.
6. **Motion Interaction Design** — motion, transitions, and interaction feedback.
7. **Responsive Accessibility** — responsive implementation and accessibility checks.
8. **Figma to Interface** — faithful implementation from Figma and supplied visual specifications.
9. **UI Visual QA** — rendered interface inspection and quality sign-off.
10. **Anti-Slop UI Audit** — diagnostic review of generic, ungrounded, or decorative UI decisions.
11. **Software Architecture & Code Engineering** — system architecture, codebase analysis, maintainability, refactoring, and verification strategy.
12. **Frontend & Backend Engineering** — end-to-end application, API, authentication, database, and integration implementation.
13. **GIS & Mapping Engineering** — spatial data, CRS, geospatial analysis, map services, web maps, and cartography.
14. **Data Visualization & Analytics** — data quality, metrics, quantitative analysis, analytical dashboards, and data storytelling.

## Operating principles

- The plugin is skills-only. It does not install a runtime, CLI, MCP server, external API, or hidden dataset.
- Skill content is an independent synthesis of public engineering and design practices. Upstream skill files are not copied wholesale.
- Skills must inspect the actual project/data and state what was not verified.
- Use the fewest skills needed for a task; the routing document defines boundaries and orchestration.
